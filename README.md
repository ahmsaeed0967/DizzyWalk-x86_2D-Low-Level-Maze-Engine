# DizzyWalk-x86-2D-Low-Level-Maze-Engine-COAL-
🕹️ A 2D arcade maze game built in x86 Assembly (MASM). Features a math-based auto-pilot engine (LCG), manual keyboard overrides, a 30x50 flattened matrix grid, encapsulated data STRUCTs, and buffered file logging to adventure_log.txt. Zero high-level abstractions—just raw machine logic, stack preservation, and direct register manipulation.
